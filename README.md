# 전기회로 실험실

중학교 「전기와 자기」 수업용 간이 전기회로 시뮬레이터입니다. PhET *Circuit Construction Kit: DC*를
참고했지만, 모바일 터치 조작에 맞춰 부품을 **전지·전구·저항·전류계·전압계·스위치·도선** 7종으로만
간소화했습니다.

- 빌드 도구 없음 (순수 HTML/CSS/JS, ES 모듈만 사용 — CDN 의존 없음)
- 조작: 격자 스냅 방식(팔레트에서 부품 선택 → 놓을 칸 탭, 총 2탭)
- 회로 해석: 전도도 행렬 기반 노드 해석(가우스 소거) — 단락·개방 회로에서도 발산 없이 안정적으로 풀림
- 오개념 힌트: 회로 미완성·스위치 열림·합선·전압계 직렬 오배치·전구 과전력을 자동 진단
- 예제 회로 6종: 기본/직렬/병렬/전류 측정/전압 측정/옴의 법칙

## 사용 방법

1. 아래 팔레트에서 부품을 하나 고릅니다.
2. 회로판의 놓고 싶은 칸(파란색으로 하이라이트됨)을 탭합니다.
3. 이미 놓인 부품을 탭하면 값 변경·극성 뒤집기·삭제를 할 수 있는 창이 아래에서 올라옵니다.
4. 상단 바에서 되돌리기·전체 지우기·예제 회로 불러오기·크게 보기를 할 수 있습니다.

같은 칸에 부품을 두 개까지 겹쳐 놓을 수 있습니다 — 전기적으로 병렬 연결과 같아서, 저항 두 개를
겹치면 병렬 저항이 되고, 전압계를 다른 부품 위에 겹치면 그 부품의 양단 전압을 측정하게 됩니다.

## 같은 저장소에 함께 있는 시뮬레이터들

「전기와 자기」 단원의 다른 소단원 학습지에 붙일 시뮬레이터를 하위 폴더로 함께 둡니다.
전부 같은 규격(빌드 도구 없는 ES 모듈, 순수 로직 분리 + `test.html` 자체 검증, 모바일 터치 대응)을
따르고, 학습지 앱의 임베드 화이트리스트에 이미 등록된 이 도메인을 그대로 씁니다.

| 경로 | 시뮬레이터 | 소단원 |
|---|---|---|
| `/` | 전기회로 실험실 | 전류·전압·저항의 관계 / 저항의 연결 |
| `/friction/` | 마찰 전기 실험실 | 1-1 마찰 전기 |
| `/induction/` | 정전기 유도 실험실 | 1-2 정전기 유도 |
| `/water-analogy/` | 물의 흐름과 전류 | 1-3 전류와 전압 |

## 배포

GitHub Pages로 배포되어 있습니다: `main` 브랜치 루트에서 서빙됩니다.

- 페이지: <https://chan7881.github.io/circuit/>
- 자체 검증: <https://chan7881.github.io/circuit/test.html> (물리 로직 자동 검증 결과)
  하위 시뮬레이터도 각자 `.../friction/test.html`처럼 같은 자리에 검증 페이지가 있습니다.

## 다른 사이트에 임베드하기

```html
<iframe
  src="https://chan7881.github.io/circuit/"
  style="width: 100%; aspect-ratio: 16 / 9; border: none;"
  allow="fullscreen"
  loading="lazy"
  title="전기회로 실험실"
></iframe>
```

`allow="fullscreen"`이 없는 iframe(또는 sandbox에 `allow-fullscreen`이 빠진 경우)에서는 화면 안의
"크게 보기" 버튼이 전체화면 대신 새 탭으로 여는 방식으로 자동 대체됩니다.

## 파일 구조

```
index.html      레이아웃 · 팔레트 · 하단 시트 · 힌트바
styles.css      반응형 3단 레이아웃(세로 폰 / 가로·태블릿 / 납작한 임베드)
js/config.js    부품 사양 · 격자 · 물리 상수
js/model.js     회로 데이터 구조, 배치 · 삭제 · 되돌리기
js/solver.js    노드 해석 회로 솔버(순수 함수)
js/hints.js     오개념 진단(순수 함수)
js/presets.js   예제 회로 6종
js/render.js    캔버스 렌더링 · 전류 흐름 애니메이션
js/input.js     포인터 좌표 → 격자 히트테스트
js/main.js      부트스트랩(DOM 이벤트 ↔ 나머지 순수 모듈 연결)
js/tests.js     solver·hints 물리 검증 케이스
test.html       브라우저에서 여는 자체 검증 페이지
```

`solver.js`·`hints.js`·`model.js`·`presets.js`는 DOM에 의존하지 않는 순수 함수라 `test.html`에서
직접 검증할 수 있습니다.
