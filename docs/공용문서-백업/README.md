# 공용 문서 백업

여기 있는 파일은 **사본이다. 원본이 아니다.**

| 사본 | 원본 (이게 진짜다) |
|---|---|
| `공통-CLAUDE.md` | `Desktop\Claude\CLAUDE.md` |

## 왜 여기 있나

원본은 `Desktop\Claude\` 아래에 있는데 그 폴더는 git 저장소가 아니다. 이 PC가
잘못되면 규칙이 통째로 사라지므로, 프로젝트 저장소에 사본을 둬서 GitHub에 남긴다.

## 고칠 때

**여기를 고치지 말고 원본을 고쳐라.** 두 곳을 따로 고치면 반드시 어긋난다.
원본을 고친 뒤 아래로 사본을 갱신한다:

```bash
cp "../../../CLAUDE.md" "docs/공용문서-백업/공통-CLAUDE.md"
```

## 복구할 때

```bash
cp "docs/공용문서-백업/공통-CLAUDE.md" "../../../CLAUDE.md"
```

## 환경 문서(`~/.claude/CLAUDE.md`)는 왜 없나

거기에는 이 PC의 드라이브 구성·원격 제어 습관 같은 **개인 환경**이 적혀 있다.
이 저장소는 공개(public)라 올리면 그대로 공개된다. 그래서 Google Drive에 따로 둔다
(`G:\내 드라이브\Claude-설정백업\`).
